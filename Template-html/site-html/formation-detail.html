Formation Impression 3D - Niveau 1

Category: Impression 3D

Duree: 2 heures
Formateur: M. Dupont
Places disponibles: 5/10

Description

Cette formation vous permettra de maitriser les bases de l'impression 3D sur les machines du FabLab. Vous apprendrez a utiliser le logiciel de slicing, a preparer vos fichiers et a lancer une impression.

A la fin de cette formation, vous serez capable de:

  • Comprendre le fonctionnement d'une imprimante 3D
  • Preparer un fichier 3D pour l'impression
  • Configurer les parametres d'impression
  • Lancer et surveiller une impression
  • Nettoyer et entretenir la machine

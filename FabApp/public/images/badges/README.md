# Bibliothèque de badges FABOS

## Badges de formation actifs

Les fichiers de `formations/` sont utilisés automatiquement par les pages **Suivi** et **Profil** selon le nom ou l’icône du badge stocké en base :

- `impression-3d.png` — Maker 3D / formation imprimante 3D
- `laser-co2.png` — découpe laser CO₂
- `soudure-electronique.png` — soudure électronique
- `decoupe-vinyle.png` — découpe vinyle
- `fraiseuse-cnc.png` — fraiseuse CNC
- `oscilloscope.png` — oscilloscope numérique
- `brodeuse-numerique.png` — brodeuse numérique
- `ultimaker-s5.png` et `prusa-mk3s.png` — variantes disponibles pour de futurs badges machine dédiés

## Badges supplémentaires

Le dossier `bibliotheque/` contient des visuels prêts à servir pour de futurs badges : sécurité atelier, initiation FabLab, autonomie machine, mentor, CAO 3D, CAM, électronique, textile, maintenance, éco-conception, projet terminé, temps machine, RFID, responsable de zone, formateur et première réservation.

Ces fichiers sont seulement des ressources graphiques. Aucune table, entité ou migration n’est créée ou modifiée.
